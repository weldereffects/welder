Welder's first public test build: a node-based compositor for real shot work, free and open source (AGPL-3.0). It runs OpenFX plug-ins, opens .nk scripts, and works in 32-bit float linear with OpenColorIO and ACES. It's a beta: try it on real shots, and tell us what breaks.

## Downloads

| | Download | Also |
|---|---|---|
| **Windows 10 / 11** | `welder-0.1.0-beta.1-win64.zip` | `-python.zip` to import .nk scripts, `-rife-models.zip` for the RIFE node: unzip them into the same folder |
| **Linux x86_64** | `welder-0.1.0-beta.1-linux-x86_64.tar.gz` | `-rife-models.tar.gz` for the RIFE node |

**Windows:** right-click the zip › Properties › tick **Unblock** before unzipping. The build isn't code-signed yet, so Windows may say "Windows protected your PC": **More info › Run anyway**. Then run `Welder.bat`.
**Linux:** unpack and run `./Welder`. Needs glibc 2.38 or newer (Ubuntu 24.04, Fedora 39, Debian 13 or later).

Both need an OpenGL 3.3 GPU. Vulkan is used for the GPU nodes and RIFE when it's there.

## What's in it

- **Editor:** viewer, node graph, properties, timeline, curve editor and dope sheet, with the classic hotkeys. Autosave with crash recovery.
- **Colour:** OpenColorIO 2.5 with ACES 2.0 built in; ACEScg working space by default.
- **I/O:** EXR (every compression, multi-part, any number of layers), DPX, TIFF, PNG, JPG; ProRes, DNxHR, H.264 and HEVC movies.
- **Roto and paint:** the classic roto toolset, open splines with width and feather per point, and cleanup paint: clone, reveal, repair (dust-busting from the frames either side, lined up along the motion), grain-matched paint, tracked paint, and strokes previewed live as you paint.
- **Keying:** ScreenKeyer, IBK, ChromaKeyer, Keyer, HueKeyer, Despill, Cryptomatte.
- **Tracking:** point and planar tracking, a 3D camera tracker, match-move and stabilise.
- **3D:** cards, cameras, geometry, ScanlineRender, Gaussian splats, and renders through your own Blender.
- **Retiming:** OFlow (optical flow) and RIFE.
- **OpenFX 1.4** plug-ins, and **.nk import and export**.
- **AI nodes** (NVIDIA GPU): AlphaGen, LTX, Depth, TrackMask (segmentation), Reconstruct, NeRF, GaussianSplat. Their models download the first time you use them, each under its own licence; check it before paid work.

## Known issues in this beta

- No macOS build yet.
- Linux needs glibc 2.38+, so Rocky and Alma Linux 8/9 can't run it yet; a build for them is next.
- Not code-signed: Windows warns before the first run.
- Pen pressure isn't read: strokes paint at full pressure.
- Deep EXR images aren't supported yet (deep parts are skipped).
- Expect rough edges: save often, and don't put it on a delivery you can't redo.

## Reporting bugs

[Open an issue](https://github.com/weldereffects/welder/issues/new/choose), or use **Help › Report a Bug...** in Welder. Include the version (Help › About Welder), your OS and GPU, what you did, and after a crash the newest file from **Help › Open Crash Reports Folder**.
