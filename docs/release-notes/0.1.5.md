Welder 0.1.5: the Mac app opens again, and RotoPaint strokes import from .nk scripts.

## Fixed

- **macOS: "Welder cannot be opened because of a problem".** The Mac downloads of 0.1.3 and 0.1.4
  needed a copy of the zlib library that only existed on the machine that built them, so Welder
  wouldn't start on any Mac, Apple silicon or Intel, whatever the macOS version. zlib is built into
  Welder now, as it is on Windows and Linux, and the Mac packaging checks that Welder needs nothing
  but macOS itself before it makes a download.
- **.nk import: RotoPaint paint and clone strokes were dropped.** Scripts saved by Nuke 16 write
  strokes differently from shapes, and every stroke was skipped with "has no curve data". Brush,
  eraser, clone, reveal, dodge, burn, blur, sharpen and smear strokes now come in with their colour,
  size, opacity, clone offset and lifetime. ([#5](https://github.com/weldereffects/welder/issues/5))

## Downloads

- **Windows:** `welder-0.1.5-win64.zip` (plus `-python.zip` and `-rife-models.zip`)
- **Linux:** `welder-0.1.5-linux-x86_64.tar.gz` (plus `-rife-models.tar.gz`)
- **macOS, Apple silicon:** `welder-0.1.5-macos-arm64.zip`
- **macOS, Intel:** `welder-0.1.5-macos-x86_64.zip`

The Mac app isn't signed yet. The first time you open it, right-click Welder.app and choose **Open**.
