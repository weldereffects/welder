Welder 0.1.6: Welder tells you why it can't start, and comps with broken node positions open again.

## Fixed

- **Windows: a window that flashes and closes, or a blank black window.** Welder used to fail
  silently when it couldn't start. Now it tells you why: a message if it can't open its OpenGL
  window (usually an old graphics driver), and a message with the crash report's location if it
  crashes. Please attach that report to an issue.
- **Safe mode.** If a start doesn't finish, the next one starts in safe mode by itself: no splash
  screen, no floating panel windows, and the default layout (the old one is kept as
  `layout.ini.bak`). You can also start it on purpose with `Welder-safe-mode.bat` on Windows, or
  `--safe-mode` anywhere.
- **"Crash opening .weld file".** A comp couldn't open at all if a node's position in the node
  graph had been saved as empty. Those nodes are placed again now, with a note in Messages, and
  Welder never saves an empty position.
- **macOS: "Welder cannot be opened because of a problem".** The fix from 0.1.5 (zlib is built into
  Welder now) is in this release's Mac downloads.

Crash reports now also say which graphics card and driver Welder was using.
