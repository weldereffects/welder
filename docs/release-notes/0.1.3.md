Welder 0.1.3: build fixes.

## Fixed

- **Linux: the RIFE node is back.** The Linux build made on GitHub (the one that runs on Rocky, Alma
  and RHEL 8 and 9) was missing it: its neural-network library was installed where the packaging
  didn't look. The release build now fails instead of shipping without it.
- **macOS: the build links again.** The neural-network library is built without Vulkan on macOS
  (which has none), so RIFE runs on the CPU there.

## Downloads

`welder-0.1.3-win64.zip` (plus `-python.zip` and `-rife-models.zip`), `welder-0.1.3-linux-x86_64.tar.gz`
(plus `-rife-models.tar.gz`). Everything else as in 0.1.2.
