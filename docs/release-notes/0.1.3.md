Welder 0.1.3: node graph improvements, Roto with overlays off, the layout after Space, and build fixes.

## New in the node graph

- **A and B along the top, masks on the side.** Nodes with more than one input (Merge, Copy,
  Switch, keyers...) take B and A on the top edge, and their mask inputs on the right side.
  Auto-align lays them out to match.
- **Right-angle pipes.** Edit › Preferences › Node Graph › Right-angle pipes draws pipes straight
  down and across with square corners.
- **Alt+drag cuts pipes.** Drag across pipes with Alt held to disconnect them (one undo step).
  Alt+drag from a node still makes copies of the selection; the middle mouse button pans. Turn it
  off in Preferences to have Alt+drag pan instead.

## Fixed

- **Roto tools come back when you click in the viewer.** With the viewer's overlays turned off (Q),
  the Roto's tools were hidden and clicks did nothing, so the Roto seemed broken. Clicking in the
  viewer while a Roto is open now turns the overlays back on, and the click goes to the tool.
- **Space no longer rearranges the layout.** After maximizing the viewer with Space and pressing
  it again, the timeline stayed at the bottom of the window instead of going back under the viewer,
  and the bottom panel always switched to the Dope Sheet. Now everything comes back as it was: the
  timeline under the viewer, and whichever of Node Graph, Messages, Curve Editor or Dope Sheet you
  had open. If your timeline is already stuck at the bottom from an earlier version, use
  **Workspace › Reset Workspace** once.
- **Linux: the RIFE node is back.** The Linux build made on GitHub (the one that runs on Rocky, Alma
  and RHEL 8 and 9) was missing it: its neural-network library was installed where the packaging
  didn't look. The release build now fails instead of shipping without it.
- **macOS: the build links again.** The neural-network library is built without Vulkan on macOS
  (which has none), so RIFE runs on the CPU there.
