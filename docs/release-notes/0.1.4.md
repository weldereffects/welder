Welder 0.1.4: panels on a second screen, and OFX plugins' buttons.

## New

- **Panels in windows of their own.** Drag a panel's tab out past the edge of the main window
  (the Viewer, Node Graph, Properties, Dope Sheet ...) and it becomes its own window, which you can
  put on a second screen; drag its tab back in to dock it again. The 3D viewer works there too.
  Floating panels are kept on whichever screen they're on. Windows, macOS and Linux under X11 /
  XWayland; not under native Wayland, which doesn't let apps place windows. `WELDER_SINGLE_WINDOW=1`
  keeps every panel inside the main window. ([#3](https://github.com/weldereffects/welder/issues/3))
- **OFX plugins' buttons.** Push buttons in an OFX plugin's panel were left out, so plugins whose
  controls are buttons showed an empty panel - NeatVideo's Prepare Noise Profile and Adjust Filter
  Settings, for example. They're shown now and pressing one tells the plugin (at the current frame,
  with its input images available). What the plugin stores when you press one, such as a noise
  profile, is saved with the script and undoes like any edit.
  ([#4](https://github.com/weldereffects/welder/issues/4))
