Welder 0.2.6: Python scripting, an MCP server for AI clients, deep compositing, a camera solve from
vanishing lines, AI masking on AMD and Intel GPUs, H.264 and H.265 export through your GPU's encoder,
more nodes on the GPU, and a large batch of fixes and requests.

## New

- **Deep compositing, part 1.** Deep images now flow through the node graph. **DeepRead** reads
  deep EXRs (scanline or tiled, by part), **DeepToImage** flattens them, and **DeepWrite** writes
  them back. Any ordinary node fed a deep image flattens it automatically. The nodes are in a new
  Deep toolbar group, and .nk import and export handle them. (#128)
- **Deep compositing, parts 2 and 3.** **DeepMerge** combines any number of deep inputs by depth
  (combine, plus or holdout), splitting volumes where samples overlap. There are new **DeepHoldout**,
  **DeepFromImage**, **DeepRecolor**, **DeepGrade**, **DeepColorCorrect**, **DeepTransform**,
  **DeepCrop** and **DeepReformat** nodes. ScanlineRender can feed deep nodes directly, hidden
  surfaces included. **DeepSample** shows one pixel's samples, **DeepToPoints** turns deep pixels into
  a point cloud, and Python and MCP can read deep samples. (#132)
- **VanishingCamera.** Draw lines along a shot's floor and wall edges on a still, and it solves the
  camera: focal length, angle and position. It can also start from a focal length you know. Set
  the scale from camera height, distance or a known length. Use the result in Scene3D, Card3D or
  ScanlineRender, bake it to a Camera node, or build a Scene3D with a floor card ready for
  CardTransform in one click. (#131)
- **Live corner pin from tracks.** The Tracker's corner pin match-move and stabilize modes are now
  solved live from its tracks. Outlier tracks are dropped, and it keeps going with 3, 2 or 1 tracks
  when corners are lost. **Fill gaps** fills frames where a track was lost, from the other tracks or
  by interpolating, and marks them so you can clear them. (#127)
- **Python scripting.** A `welder` Python module drives Welder: comps, nodes, knobs, keys,
  expressions, pixels as numpy arrays, and renders. `welder python script.py` runs a script
  headless. In the editor, **Scripts › Script Editor** runs Python with output underneath, and
  undoes each run in one step. The Scripts menu lists your script folder, and `init.py` runs at
  startup. Any Python 3.8 or newer works, including your own venv. See docs/PYTHON.md. (#117, #119)
- **Python callbacks and buttons.** In `init.py`, `welder.on(...)` runs your code when a comp is
  opened or saved, a knob changes, a node is created or deleted, the frame changes or the selection
  changes. Nodes can carry buttons that run Python. They're saved with the comp. (#121)
- **MCP server.** Claude Desktop, Claude Code and other MCP clients can work in the open comp: make
  and connect nodes, set knobs and keys, render, and look at any node's picture. It's off by default.
  Turn it on in **Edit › Preferences › MCP server**, which also copies the client setup for you. It
  listens on this computer only and needs a token. Each change is one undo step. See docs/MCP.md.
  (#122)
- **H.264 and H.265 export.** Write writes H.264 and H.265 (including 10-bit Main 10) to MP4, MOV or
  MKV through your GPU's own encoder: NVIDIA NVENC, AMD AMF, Windows Media Foundation (Intel and
  Windows' built-in encoder) or Vulkan Video. It has constant quality or bitrate, plus profile,
  speed and keyframe controls. (#124)
- **Saved workspaces.** **Workspace › Save Workspace...** keeps up to six named layouts. Switch
  between them from the menu or with Shift+F1 to F6. (#103, #112)
- **Floating panels.** Tick **float new panels** in the Properties bin, and nodes you open from
  then on get their own windows. These stay above Welder's other windows. (#105, #112)
- **Metadata.** Read passes on each frame's metadata, including every EXR header attribute. New
  **SetMetadata** and **CopyMetadata** nodes edit it, Write puts it back into EXR headers,
  **Viewer › Metadata** shows it, and Text can show it with `[metadata key]`. (#99, #112)
- **Smart vectors.** SurfaceLock can output its warp as an ST map, and the Tab search finds
  VectorGenerator and SurfaceLock under "smart vector". (#106, #112)
- **Roto.** Double-click a shape to select all its points. Right-click in the viewer for a shape
  menu (keys, smooth or cusp, open or close, lock, duplicate, delete and more). Ctrl+C and Ctrl+V
  copy points to another frame or another shape, and set a key there. This applies to Roto,
  RotoPaint and Power Roto. (#20, #115)
- **CorridorKey key folder.** A new **key folder** knob saves each finished key as EXRs, so render
  nodes and other artists use the same key. Without the key, the render now stops with a clear error
  instead of quietly passing the plate through. TrackMask's bake folder gets a folder browser too.
  (#77, #116)
- **Font picker.** Font knobs (Text, Slate, CodeRain, LayerContactSheet) get a dropdown of installed
  fonts with search. **...** now browses for font files. (#108, #112)
- **Node graph.** Dragging to the graph's edge scrolls it (#109). Holding middle and left together,
  as with a pen's side button, zooms (#104). (#112)

## New: AI

- **AI masking on AMD and Intel GPUs.** TrackMask, text find, the matte refiners, CorridorKey and
  Depth now run on AMD (ROCm, or DirectML on Windows) and Intel (XPU) GPUs as well as NVIDIA, and
  fall back to the CPU when a GPU can't run a model. **Set up ML** detects your GPU and installs the
  matching PyTorch. (#129)

## Faster

- **More nodes on the GPU.** Grade, ColorCorrect and the other colour nodes, Merge (all 25
  operations) and Transform motion blur can run on the GPU, with the CPU as the fallback. Welder
  times each job both ways and uses whichever is faster on your machine. `welder gpu-bench` shows
  the numbers. (#123)
- CorridorKey writes and reads its frames on several threads. (#116)

## Fixed

- **TrackMask only tracked the first frame on long, high-res shots.** Frames are now cached at the
  tracker's working size, so a 4.6K shot needs about 1/13th of the disk. Long shots stream through
  memory, so a 1600-frame 4.6K track no longer runs out of RAM. (#133)
- When an ML job can't start, the ML panel now shows why next to the button, for example a full
  cache disk. (#133)
- **CorridorKey: "module torch has no attribute cuda".** This came from a half-installed PyTorch.
  Set up ML now checks that each PyTorch install loads and reinstalls a broken one, and CorridorKey
  and the ML panel say what's wrong. If you saw this error, click **Update ML** once. (#129)
- **Denoise** now cleans blotchy, low-frequency noise as well as fine grain. It has new **low
  frequency** and **scales** knobs, and a separate noise level for blue and red. (#78, #118)
- SplineWarp and SplineFlow controls stopped working with a shape selected. (#100, #112)
- At wide zoom, clicking a small node grabbed its pipe ends instead. (#111, #112)
- The ML worker kept its memory after Welder quit. Now the last Welder to quit stops the worker
  it started. (#81, #112)
