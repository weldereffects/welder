Welder 0.1.7: Photoshop files with their layers, a timecode node, floating property windows, and
fixes for plugins that crashed Welder at start, Retina screens and Wayland desktops.

## New

- **Photoshop files (.psd, .psb).** A Read node brings in the composite as RGBA and every layer as
  channels of its own, named after it (a layer "Sky glow" is `Sky_glow.R/G/B/A`), in its place on
  the canvas. Hidden layers come in too. Each layer's visibility, opacity and blend mode are in the
  Metadata tab. RGB and grayscale, 8, 16 and 32-bit. (#12)
- **AddTimeCode.** Stamps a timecode on the frames: the start code on the project's first frame (or a
  frame you pick), at the project's frame rate or its own. Write puts it in the header of EXR files.
  Imported from .nk scripts too. (#13)
- **Floating property windows.** Right-click a panel's title in the properties bin (or a node in the
  graph) and choose to float it: it opens in a window of its own, with **OK** and **Cancel**. Cancel
  puts the knobs back as they were when the window opened, so you can try things and back out. (#25)
- **Nodes with problems are marked in the node graph.** Red: a node type this build doesn't have, or
  the node the viewer's render failed in. Amber: a node the .nk import could only approximate. Hover
  for the reason. (#11)
- **Ctrl+F finds a node** in the node graph (as / does), and it's in the right-click menu. (#10)
- **Middle-drag zoom for tablets.** Edit > Preferences > Middle-drag zooms: a middle-button drag
  zooms the node graph and the viewers, for pens without a scroll wheel. Alt+middle-drag always
  zooms. (#23)
- **UI scale.** Edit > Preferences > Appearance > UI scale, from 75% to 250% (takes effect the next
  time Welder starts).
- **Nuke Indie and Non-commercial scripts.** File > Import accepts `.nkind` and `.nknc` scripts. When
  Nuke saved them encrypted, Welder says so: copy the nodes in Nuke and paste them into Welder. (#18)

## Fixed

- **Welder crashed at every start because of an OFX plugin.** A plugin that crashes while Welder
  loads it (as a denoiser did) is now skipped from the next start on, with a message. Edit >
  Preferences > OFX lists the skipped plugins and can try them again. (#8)
- **macOS: everything twice as big on a Retina display.** (#17)
- **Linux: clicks landing in the wrong place, menus not opening, nodes snapping back** on desktops
  that run Wayland (Ubuntu 22.04 and later). Panels stay inside the main window there; set
  `WELDER_FLOATING_PANELS=1` to float them anyway. (#9)
- **FrameHold on a camera.** A FrameHold (or TimeOffset, or a Dot) in a camera's pipe now holds the
  camera, the usual way to freeze a projection camera. (#24)
- **Saving over a file asks first** in the Save dialogs. (#15)
- **Pasting nodes whose position was empty** no longer fails. (#14)
- The Mac packages can no longer be built without FFmpeg by mistake (0.1.4 for Apple silicon
  couldn't read .mov or .mp4 files). (#21)
